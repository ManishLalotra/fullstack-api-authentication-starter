# fullstack-api-authentication-starter

> Production-grade authentication microservice with JWT rotation, Redis revocation lists, TOTP MFA, and Role-Based Access Control.

## Overview
A hardened, battle-tested authentication and identity microservice. Features access/refresh token rotation, Redis session storage, rate limiting, and comprehensive threat modeling.

## Features
- Access token (15m) + refresh token (7d) rotation pattern
- Redis token revocation blacklist
- Role-Based Access Control (RBAC) middleware
- Multi-factor authentication (TOTP QR codes)
- Jest and Supertest test suite
